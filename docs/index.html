İndirmeni doğrulamak istersen (opsiyonel)

Zorunlu değil. Sağlama ve imza dosyaları GitHub Release sayfasındadır. Bozulmadan geldiğinden emin olmak için tek komut:

sha256sum -c ShalaOS-*-Dardania-x86_64.iso.sha256

İleri düzey — ShalaOS tarafından yayımlandığını GPG ile doğrula:

gpg --import KEYS
gpg --verify ShalaOS-*-Dardania-x86_64.iso.sig ShalaOS-*-Dardania-x86_64.iso
